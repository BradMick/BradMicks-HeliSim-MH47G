# MH-47G - HeliSim

## Requires

| mod | why |
|---|---|
| BradMick's HeliSim 1.3.0.0 or later | the flight model this pack drives |
| Pegasus Systems MH-47G Block 1 & 2 | the MH-47G itself (`PGS_Hooker_Core`, `PGS_MH47G_Block_1`) |
| CBA_A3 | HeliSim's dependency |

Load all three in game. This pack loads after HeliSim and after the Pegasus Systems MH-47G.
The Block 1 and Block 2 both inherit from `PGS_Chinook_Base`, so both fly this model.
